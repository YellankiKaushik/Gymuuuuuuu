# Test navigation

All 145 original test/support/fixture files retain their paths. No tests were deleted or physically moved. Filename-based classification below is navigation; several files cover both unit and integration boundaries. Vitest still discovers `tests/**/*.test.{ts,tsx}`; Playwright retains the browser, audit and closure directories. Root-level imports, fixture paths, named CI cases and historical evidence bindings remain stable.

Use `npm run test:unit`, `npm run test:coverage`, `npm run test:e2e:cross-browser`, `npm run test:a11y`, `npm run test:routes` and `npm run test:closure` as documented in the [project README](../README.md#development-and-verification). The three tests that read original reference JSON now use archived paths.
