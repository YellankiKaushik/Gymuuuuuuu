# Exercise encyclopedia

Phase 03 owns exercise identities, taxonomy, technique and sources. Catalogue: `/exercises`; details: `/exercises/$slug`. Preserve `exercise_*` IDs for programs and workout records. The supplied taxonomy is copied unchanged into `src/content/exercises/taxonomy.json`. All 184 draft identities are parsed with the envelope version; publishable factual records belong in `records.json` (currently empty).

Strict Zod schemas mirror the supplied record fields and strengthen practical publication requirements. Invalid numeric ranges, missing source/confidence, self references, contradictory roles, incomplete steps, missing critical reviews and incomplete reviewed-media metadata are rejected. Cross-file validation checks anatomy/movement/equipment IDs, all claim source IDs, relationships, duplicates, stable slugs and review freshness. Published relationships must target published records. The source schema's version-regex escaping error is corrected to accept ordinary semantic version strings.

ID, slug, alias, movement, equipment, muscle, relationship and normalized search indexes derive from validated records. Fixture indexes are cached per array. Search indexes muscle names and reviewed aliases, equipment, movement and goals. Filters use OR within each group and AND across groups. URL values are sanitized, card/list preference is local. TanStack may serialize multi-value query arrays as JSON; the parser also accepts comma-separated strings.

Details show practical instructions first, semantic ordered steps, an optional gym mode that keeps safety visible, print controls, qualitative muscle roles, corrections, relationships, separate contextual programming ranges, sources and critical review dates. Missing numeric fields remain unavailable. Retired routes use the explicit migration map when a published replacement exists; otherwise they show a safe retired state. Draft and unknown routes are unavailable and noindex.

No media request is made before the user acts. Reviewed YouTube links generate allowlisted privacy-enhanced iframe URLs with autoplay disabled, standard controls, and captions requested when available. Unsupported providers remain external links. Cross-origin player restrictions cannot reliably be detected by iframe `error`; an explicit written-steps fallback and external link remain available. Minimum player height is 200px even on narrow screens. Media is never downloaded or mirrored.

`npm run validate:content` prints coverage by movement, equipment, body region and primary group plus missing regression/media/review lists. Current public count is zero. Synthetic test content is under `tests/fixtures` and is never imported into production content. `npx tsx scripts/inspect-exercise-fixture.tsx` checks that template in five viewports and two themes without contacting media providers.
