# Recipe calculation methodology
Ingredient amount = source per-100-g value × edible grams / 100. Retention precedes density. Approved factors match nutrient, food group, method and release; matching already-cooked profiles skip duplicate processing. No factors are currently approved. Cooking without a factor makes values unavailable unless the user explicitly permits labelled unadjusted estimates.
Batch totals sum quantified contributions; missing and trace are null. Coverage reports known/eligible ingredient counts and masses, with unknown masses separately disclosed. Partial component calculations remain partial through nested recipes and consumed snapshots. Final edible weight excludes containers; measured serving weight takes precedence over count-based averages. Ingredient-sum yield is limited to no-cook recipes. Default reconciliation tolerance is 2%; deviations require a reason and lower grade.
Grade A requires an approved analysed composite, currently unavailable. B/C/D/E describe ingredient/yield/retention evidence and are not health scores. User-entered composition remains Grade E. Calculations preserve internal precision; display rounding never changes canonical values.
