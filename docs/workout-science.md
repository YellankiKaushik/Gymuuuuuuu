# Workout science

Canonical routes: `/learn/workout-science`, `/learn/workout-science/$slug`, `/learn/workout-science/methods` and `/learn/workout-science/glossary`. The original `/training-science` route redirects to the canonical catalogue. Shared navigation, learning hub, breadcrumbs and module finder use the current routes.

The 98 unchanged seed identities are private drafts in `src/content/workout-science/taxonomy.json`. Factual records belong in `records.json` (currently empty). Zod mirrors the complete JSON record schema, corrects its double-escaped semantic-version regex, requires non-null publication fields and validates consistent numeric bounds. Atomic claims require source IDs, population, evidence level, confidence, direction, limitations and verification date. A topic needs three to six takeaways and a complete six-part decision framework. Deprecated records require a replacement and migration note.

Cross-file validation checks stable slugs, duplicate identity/claim/source IDs, topic/exercise/muscle references, source resolution, prerequisite cycles, future review dates and review intervals. Quantitative guidance and advanced methods use an annual interval; stable topics use at most two years. Overdue published articles remain identifiable with a review-due badge and report; due dates do not silently rewrite historical content. Universal wording in practical content requires an explicitly reviewed, sourced exception in `language-exceptions.json`. Medical diagnosis/treatment language is rejected. Language checks support subject review and do not certify factual accuracy.

Generated indexes contain published ID/slug, aliases/abbreviations, categories, goals, experience, topic graph, exercise reverse links, glossary and source-to-claim mapping. Search excludes draft prose. Cached fixture indexes demonstrate responsiveness with 500 records. Public filters use OR within groups and AND across groups; URL defaults are removed using the router's search middleware. Back/forward and reload restore filters. Learning paths organize topics by goal/experience and learning order without creating a personal goal. The methods view fixes its category to advanced methods.

Topic pages place key takeaways and the decision framework before deeper evidence. Expandable atomic claims retain population and limitation details. Numeric units, qualifiers and context appear together. Comparisons stack on mobile and use each topic's definitions, practical levers and limitations. Glossary terms include deduplicated aliases/abbreviations and alphabet anchors. Section targets are focusable and offset below the header. Exercise pages link only published science topics; science pages link only published exercise details and never copy technique.

Saving/reading-history UI is optional in this phase and is reserved for the general saved-items contract in Phase 16. No profiles, inferred goals or reading-history telemetry were added.

Commands: `npm run validate:content`; `npm run check`; `npx playwright test tests/browser/science.spec.ts`; `npx tsx scripts/inspect-science-fixture.tsx`. The synthetic fixture is never imported into production records. Source links are external and no source page is fetched at runtime. Release-time live source checks belong to Phase 18.
