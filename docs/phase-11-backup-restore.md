# Phase 11 backup and recovery
Full JSON contains preferences, all local identity/version collections, batches, groceries, favourites, audit and consumption intents. Migration marker is internal. Public static content is not personal backup data. Five CSVs export ingredients, recipe nutrition, calendar, planned nutrition and grocery lists, retaining status/provenance and escaping spreadsheet formulas.
Validation precedes every write. Keep-existing adds noncolliding records; import-copy remaps structured identifier fields without rewriting free text; confirmed replacement atomically clears/replaces only this module's ten stores. Explicit replacement can recover corrupt local records without requiring the old records to validate. Transaction abort preserves existing records. Normal malformed reads expose a read-only isolated view and raw recovery export; raw files are not directly importable until repaired and validated.
A committed consumption journal may reference a diary entry not present on another browser. Imported plans never cause automatic consumption. Pending intents need explicit retry. Typed DELETE RECIPES AND PLANS plus confirmation clears only this module. Export before browser cleanup; persistence grants do not replace backups.
