# Composition methodology

Food composition is stored per 100 g edible portion. A serving of `grams` scales each numeric amount and numeric bound by `grams / 100`. Zero/negative, nonfinite and over-10,000-g servings are rejected. Raw and cooked profiles remain separate; no generic cooking-loss formula is invented.

Measured, calculated, imputed and estimated values retain their original status. Estimates and imputed values require documented methods and can be excluded from numerical search. Trace, not detected and not available remain nonnumeric; a documented bound can be retained without substituting it for an amount. Explicit source zeros remain zero.

Completeness counts registered nutrients with numerical amounts, with the denominator of 44 registry nutrients visible. It is data coverage, not a food-quality rating. Comparisons retain each profile's source and preparation state, and compute differences only when both values are numeric and use the same canonical unit and serving basis. No health ranking, daily-value percentages or personal recommendations are inferred.

Serving choice is transient browser state. Factual records remain immutable. Nutrient education and reference intake tables belong to Phase 08, calculators to Phase 09, logging to Phase 10, and recipes to Phase 11 under the individual phase packages.
