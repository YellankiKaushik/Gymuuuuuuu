# Food source policy

The pinned reference registry follows the supplied source hierarchy: USDA Foundation April 2026, FNDDS 2021–2023 published October 2024, then SR Legacy April 2018. Source records must carry the exact registry release, external description/ID when applicable, access date, match type, license note and full citation. Close matches require limitations. Publication requires numeric and editorial signoff; a downloaded dataset does not imply review.

[USDA's API guide](https://fdc.nal.usda.gov/api-guide/) confirms that FoodData Central data is public-domain CC0 and requests attribution. The [official download page](https://fdc.nal.usda.gov/download-datasets/) lists the pinned releases. Public pages retain attribution in each profile's citation and link to the official source. No API key is used or exposed, and the application never calls FDC at runtime.

The [ICMR-NIN website](https://www.nin.res.in/downloads/) footer prohibits reproduction, distribution and automated scraping without prior written permission. No NIN data was scraped, copied or redistributed. Its current registry entry remains reference-only. FAO/INFOODS guidelines govern nomenclature, food matching and conversion review; they do not supply nutrient amounts. Any future permitted source expansion requires a reviewed registry/schema change, documented rights and explicit import provenance.

No composition dataset has been imported into this release. Synthetic test records are kept under tests only and never included in public shards. Food media must be local, rights-cleared and properly attributed before publication; no unlicensed image assets are supplied.
