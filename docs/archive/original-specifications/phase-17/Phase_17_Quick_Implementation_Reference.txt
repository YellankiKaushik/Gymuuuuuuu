CORE RULES
- Browser storage is not a backup.
- IndexedDB canonical; localStorage only approved non-sensitive preferences.
- Discover actual stores; do not guess or rename blindly.
- Back up canonical records; exclude derived caches and active timers.
- Default portable JSON excludes photo binaries.
- Full-media package is explicit.
- Validate and hash before download.
- Restore preflight writes nothing.
- No field-level auto-merge.
- Multi-database restore is recoverable, not atomic.
- Persistent-storage request may be denied.
- Quota is approximate.
- No unload-time backup.
- CSV is not a restore format.
- Spreadsheet-safe CSV is default.
- No cloud sync, backend or personal-data transmission.
