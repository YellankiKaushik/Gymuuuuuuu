# Original specifications archive

This is the original Phase 00–18 source package, relocated from `DOCS_for_entire_apppliaction/GYM/` during the repository organization task. All 114 original files retain their original names and byte content. All 19 phases are represented. Formats remain Markdown, DOCX, JSON and plain text; nothing was converted or removed.

Each `phase-NN/` directory contains that phase's original specification, prompt package, schema, taxonomy and/or reference data, as originally supplied. The five Phase 18 files with `(1)` in their names are intentionally preserved in [phase-18/legacy-copies](phase-18/legacy-copies/). They may duplicate other historical artifacts and are not necessarily current operational guidance.

Original prose, source references and historical omissions remain intact. In particular, no missing Phase 17 Markdown document has been fabricated. Current product documentation and decisions can supersede historical implementation guidance; start with the [documentation index](../../README.md). Historical reports retain the paths that existed at the commit they audited. Resolve an old path through the [move manifest](../../reports/repository-reorganization-manifest.md), rather than rewriting old evidence.

The Phase 06 reference JSON remains an imported runtime contract at its archived path. Its bytes are unchanged; importing code was updated only to resolve the new location. Schema generators, release-manifest tooling and tests use the new paths. Do not edit archived inputs to update present-day guidance.
