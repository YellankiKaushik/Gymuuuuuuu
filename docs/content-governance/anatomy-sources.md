# Anatomy source and media policy

Canonical identities follow the supplied taxonomy, with IFAA/FIPAT as the specified nomenclature baseline: https://ifaa.net/committees/anatomical-terminology-fipat/. Source metadata includes publisher/title/URL/type, usage conditions, supported fields, limitations and actual check dates. AI is not a source and a source check is not an independent expert review.

OpenStax's current Anatomy and Physiology 2e pages carry CC-BY-NC-SA and additional usage notices. Treat them as link-only references until reuse conditions are deliberately satisfied: https://openstax.org/books/anatomy-and-physiology-2e/pages/11-5-muscles-of-the-pectoral-girdle-and-upper-limbs. NCBI references must be checked per article for both content and licensing. Do not copy proprietary text/images or download demonstrations.

The body-region silhouette is original project-owned inline SVG in features/muscles/body-selector.tsx, with abstract, approximate region positions. Its visible caption and SVG description identify it as a navigation aid, not factual anatomy imagery. No third-party illustrations were reused. Future media needs immutable IDs, subjects/orientation, caption/alt, creator/license/attribution/modification/review metadata and clearance before publication.
