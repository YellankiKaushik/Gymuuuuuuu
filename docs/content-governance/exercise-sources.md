# Exercise publication and media policy

Do not use draft identities as technique guidance. Publish only records whose anatomy, technique, numeric programming and safety claims have reviewed sources. Video is supplementary visual evidence and cannot be the sole factual source. Source IDs resolve inside each exercise's source list; shared anatomy references use Phase 02 identities.

The required publication workflow is identity/classification → sourced muscle roles and actions → setup/execution → mistakes/corrections → relationships → contextual programming → safety → media review → technique/anatomy/safety/media review → schema and relationship validation → publication. No automated content completion is permitted. Critical reviews older than 24 months and overdue review dates block publication. Later phases must not rewrite exercise technique.

Store creator credit, license state, selection rationale, review date, embed permission and caption availability for each reviewed medium. Use original summaries and properly licensed visuals. Third-party videos remain links, never scraped downloads. Player behavior was checked against [YouTube player parameters](https://developers.google.com/youtube/player_parameters) and [YouTube embedding guidance](https://support.google.com/youtube/answer/171780?hl=en) on 4 October 2026.

The supplied 184 identities contain no source-reviewed technique or media. The implementation does not invent these fields. Content coverage and human review remain outstanding.
