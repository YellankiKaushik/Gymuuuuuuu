# Manual meal planning
Plans contain 1–28 explicitly dated days, browser time zone, frozen meal slots, optional diet targets and optional compatible references. Manual recipe servings, resolved food snapshots and placeholders are supported by strict contracts. Placeholders never supply zero nutrition. Totals are known contributions with per-nutrient completeness; averages divide by known days and report the denominator. Materially incomplete rows cannot support target difference claims.
No menu is generated to fit targets. Public templates require independent review and exact published source versions. The current public release contains none. Batch production and allocations are separate: leftovers cannot precede production or exceed serving equivalents. Meal movement and copying use labelled keyboard-operable controls.
