# Owner-requested design reference integration

The October 17, 2026 request authorizes a bounded presentation improvement to the
current completed implementation. It does not start a new content phase. Both
required GitHub repositories and the local source, existing Phase 19 plan/handoff,
Progress schema and restore preparation path were inspected before edits.

The reference collection contains website design analyses, not a component
dependency. The project-specific root DESIGN.md translates NerdWallet (primary),
IBM (forms/data) and Oura (wellness) into original Fitness OS rules. The supplied
research report was read as supporting material; its instructions, estimates and
additional reference suggestions were not adopted as owner authorization.

The implementation retains existing base brand colors and system fonts. It
normalizes corner, control-boundary, foreground and warm-surface tokens; improves
the Home hierarchy and natural heading wrapping; strengthens tone borders and
comparison labels/values; and gives data-management controls clear boundaries.
Progress replaces hard-coded blue/gray boundaries and focus colors with the
existing theme vocabulary. Home's storage copy uses ordinary browser language.

All routes, storage services, schemas, source-backed content, accessible labels,
save/restore behavior and theme preference logic are preserved. No dependency,
font, company asset, runtime service or external storage is introduced. Only
presentation and supporting project documentation are in scope. The current-run
verification and remaining limitations belong in reports/design-reference-integration.md.
