# Source-unspecified program durations

NHS strength guidance reviewed 21 July 2026 explicitly gives no strength-session duration. Requiring a fabricated numeric estimate to publish a source-backed program conflicts with the Phase 19 source policy.

The Phase 05 runtime extension now permits explicit null session and weekly durations only with source-unspecified provenance. Published records cannot mix that state with numeric durations. Existing NIA immutable versions retain their source guideline allocations. The generated original Phase 05 contract is preserved.

Derived fixed and rotating summaries propagate any unknown duration as unknown; no missing duration is converted to zero. Catalogue, detail, comparison and current-program screens show “Duration not supplied” without a minute unit or false allocation label. The time-limited Finder excludes unknown-duration programs, even for a large time budget. A separately labelled, explicit no-time-limit choice may include them and explains their unknown duration; invalid numeric input remains rejected. No automatic time estimate or exercise calorie value is inferred.

Regression checks cover null provenance, missing provenance, mixed numbers, rotating totals and Finder exclusion. Source-backed general templates must still pass all remaining publication, relationship, version and source checks before being added.

The stable general-fitness two- and three-day seed IDs, slugs and names are preserved. Their publication prerequisites explicitly require prior instruction in intermediate ACE techniques; their audience is consequently intermediate rather than implying that an uninstructed foundation/beginner user can follow them. Both retain the gym/full-gym catalogue context while listing the actual required bench, dumbbells and floor space. Numeric framework, safety and warm-up links are attributed to inspected NHS pages; static combinations, calendar placement, counting conventions and substitution options are original repository work and carry no equivalence, superiority or publisher-endorsement claim.
