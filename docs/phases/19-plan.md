- [ ] Populate conservative recovery, cardio and supplement education/routines with specific populations, methods, safety boundaries and sources.
- [ ] Rebuild search with public factual records, correct adapters, publication gates, hashes, deep links and compatible comparisons.
- [ ] Record media rights/attribution; add original accessible SVGs where useful.
- [ ] Review the whole product at 320px, tablet and desktop in both themes, including keyboard, loading/error/empty states and print.
- [ ] Run all automatic gates, retain exact evidence, update README and handoff, commit and push. Create the completion tag only if the definition of done is actually satisfied.

Source verification is not independent human or clinical review. No dataset match, numeric value, fitness claim, licence, review date, yield measurement or test result may be invented. Remaining gaps must stay unavailable and be reported with specific reasons. Production deployment and domain connection remain disabled.
