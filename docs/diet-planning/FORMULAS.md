# Formula integrity and sources

All supplied factual constants are preserved in src/content/diet-planning/reference.json, copied from the original Phase 09 reference file. The domain module owns calculations, conversion constants, normative input/output bounds and rounding tolerances; UI calls it and displays its constants.

Energy: EER = intercept + ageCoefficient × ageYears + heightCoefficient × heightCm + weightCoefficient × weightKg, using the selected one of eight coefficient records. Goal energy uses EER × (1 + adjustmentPercent / 100), or an explicit bounded manual input. Protein uses selected g/kg × explicit calculation weight. Fat uses target × percent / 100 / 9. Carbohydrate uses (target − protein × 4 − fat × 9) / 4. Fibre benchmark uses target / 1000 × 14. BMI uses kg / metres². No intermediate calculation is rounded.

Primary source checking on 2026-10-05: [National Academies 2023 Tables 5-4, 5-5 and 5-6](https://www.nationalacademies.org/read/26818/chapter/7) match all eight equations, PAL bands and RMSE values. The reference file rounds model MAPE to approximately 9%; source Table 5-5 reports 9.4% and 8.7%, while Table 5-6 rounds to 9. [NIDDK planner](https://www.niddk.nih.gov/bwp) confirms its 1,000 kcal boundary; our intended population is the source-equation adult group aged 19+, stricter than NIDDK's 18+ interface.

[ISSN's 2017 original position stand](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/?uid=36307aead3657s16) supports the exercise protein context. The regular-exercise 1.2–1.6 range is the specification's narrower planning preset, not a claim that it reproduces the full sports position statement. Adult AMDR, general protein reference and fibre benchmark are supplied by the [2005 National Academies report](https://doi.org/10.17226/10490); the rendered summary's numeric tables were not readable through text browsing in this session, so no independent full-table review is claimed. Source checking is engineering verification, not professional review of an individual plan.
