# Nutrient methodology

The Nutrient Encyclopedia uses the supplied strict schema and 51 stable identities. Forty-four IDs map to Phase 07 composition. Draft topics remain hidden; source-checked framework/glossary explanations are a separate reference layer and contain no numeric intake tables.

Public topics require exact approved evidence-claim coverage for summary, functions, absorption, interactions, training statements, conversions and risk overviews; cited source records; canonical identity mappings; approved compound scientific/editorial review; and medical boundaries. Numerical references preserve the framework's value type, population, basis and source. The companion dataset manifest supplies the version/authority omitted by the normative row schema, without adding fields to the original contract.

Integer-month age bands are inclusive. Overlapping age/sex/life-stage rows of the same framework and value type are rejected; resolution fails closed rather than choosing arbitrarily. No row is distinct from an explicitly unestablished value and from a genuine numeric zero. Ranges require a range-compatible value type and explicit percentage-energy basis. Body-weight-based references remain separate; no weight input or gram target is inferred.

Plain mass-unit conversions preserve the same concept. Other forms and equivalent systems require an approved HTTPS-source conversion rule scoped to nutrient, form, framework and version. The supplied niacin and vitamin E units differ between Phases 07 and 08, so matching IDs alone never authorize percentages. Vitamin D IU conversion also requires an explicit approved rule. No RAE, DFE or NE totals are reconstructed from incompatible measurements.

A compatible percentage uses a verified numeric amount divided by a selected positive scalar daily/label reference, multiplied by 100. Its returned metadata names the framework version and population. Upper-limit percentages are explicitly informational, never goals. Missing, range, per-body-weight and incompatible values are rejected; rounding occurs only in display.

Food rankings are precomputed from validated published Phase 07 foods and approved profiles, with per-100-g, per-100-kcal or source-backed-portion bases. Estimates, imputed amounts, energy statuses, portion statuses, raw/cooked labels and releases remain visible. Missing values, incompatible units and zero-energy denominators are excluded. No ranking calls a food universally best. Full food records are not loaded on nutrient pages.

Reference age, sex and life stage stay transient unless the user clicks Remember. Remembered populations live in IndexedDB and can be forgotten independently; framework ID alone is a small localStorage preference. No personal inputs enter URL construction, server rendering, source requests or metadata. All reference data comes from static lazy repository loaders.
