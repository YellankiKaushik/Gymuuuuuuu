# Content review and publication

The supplied seed contains 51 identities, all draft and unpopulated. Public topic count and reference-row count are zero. Source-checked glossary definitions are available independently. `release-report.json` tracks draft/partial/public counts and hashes editorial input. There is no review CMS or remotely stored content.

Publication requires strict schema validity, immutable identity/mapping consistency, citation completeness, exact approved claim coverage, correct forms and units, signed scientific/editorial approval, population/reference consistency, and medical boundaries. The normative schema contains one compound editorial review object; no separate unsupported fields are added. The approved reviewer must attest to both required reviews in the editorial notes.

Article dietary-pattern context is represented by approved `other` claims with explicit population/context text because the normative schema has no separate dietary-pattern field. Related links resolve only to public topics. Food rows link to public nutrient pages only when a reviewed index entry exists.

Release gates remain real scientific/editorial reviewers, rights-cleared versioned intake datasets, actual authoritative citations for all medical/athletic claims, reviewed food profiles from Phase 07, and manual human/device accessibility review. Test fixtures do not satisfy factual publication review and must never be copied into the public release input.
