PROMPT 4 - RECIPE CALCULATION AUDIT
============================================================
Inspect the implementation specifically for recipe-calculation corruption risks.

Verify:
1. Every nutritive ingredient resolves to grams.
2. No generic volume conversion exists.
3. Every canonical ingredient stores a food/profile/source snapshot.
4. Retention is applied to nutrient amount before final-yield density.
5. A cooked profile is never adjusted for the same cooking step twice.
6. Missing values remain missing.
7. Trace values are not silently converted to zero.
8. Source energy is not replaced by macro-derived energy.
9. Final batch weight excludes container weight.
10. Serving and batch weights reconcile or show a downgrade warning.
11. Cached calculation summaries can be deleted and rebuilt exactly.
12. Historical versions are independent of current Phase 07 data.

Report every violation by file and line. Fix none until the correction prompt is approved.
